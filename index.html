Analisis dihitung dari catatan historis yang sudah berhasil dimuat. Nilai rata-rata bukan hasil prediksi kondisi tanaman.

1. Mengenal Smart Garden

Smart Garden adalah sistem penyiraman tanaman otomatis menggunakan ESP32 dan sensor. Suhu (DS18B20) berperan sebagai komponen utama untuk memantau kondisi lingkungan dan menyesuaikan ambang kelembapan penyiraman bersama sensor tanah, lalu mengendalikan pompa secara aman.

2. Komponen Sistem

  • ESP32 DevKit sebagai pengendali utama.
  • DS18B20 sebagai sensor suhu utama pemantau lingkungan.
  • Soil Moisture Sensor untuk mengukur kelembapan tanah.
  • Relay sebagai pengendali pompa.
  • Pompa air untuk penyiraman otomatis.
  • LCD I2C untuk menampilkan informasi lokal.
  • Firebase untuk menyimpan dan menyinkronkan data.

3. Cara Mengoperasikan

  1. Pastikan rangkaian ESP32 sudah terhubung dengan benar.
  2. Pastikan sensor dan pompa sudah terpasang.
  3. Hubungkan ESP32 ke jaringan WiFi yang dikonfigurasi.
  4. Pastikan ESP32 berhasil terhubung ke Firebase.
  5. Buka website Smart Garden.
  6. Periksa suhu dan kelembapan pada dashboard.
  7. Amati status tanah dan pompa.
  8. Buka menu Historis untuk melihat catatan sebelumnya.

4. Cara Membaca Dashboard

  • Suhu: menunjukkan pembacaan utama sensor DS18B20 dan memengaruhi batas nyala pompa saat suhu tinggi.
  • Kelembapan: menunjukkan nilai pembacaan sensor tanah.
  • Kondisi tanah: menunjukkan kategori gabungan suhu & kelembapan sesuai program ESP32.
  • Pompa ON: sistem melaporkan pompa aktif.
  • Pompa OFF: sistem melaporkan pompa tidak aktif.

5. Cara Melihat Historis

  1. Pilih menu Historis Sensor.
  2. Masukkan tanggal awal dan akhir.
  3. Gunakan kolom pencarian untuk mencari status tertentu.
  4. Pilih filter pompa jika diperlukan.
  5. Tekan Export CSV untuk menyimpan hasil pencarian.

6. Pemecahan Masalah

Data tidak muncul: Periksa koneksi ESP32 dan Firebase.

Suhu menunjukkan --: Periksa sensor DS18B20 dan data yang dikirim.

Kelembapan tidak terbaca: Periksa kabel dan pembacaan analog.

Historis kosong: Pastikan ESP32 sudah mengirim catatan ke path Riwayat.

Website tidak terhubung: Periksa Firebase URL, konfigurasi aplikasi, dan aturan database.

Catatan: Website ini merupakan sistem monitoring. Pengaturan ambang suhu/penyiraman dan kendali relay tetap berada pada program ESP32.

🌱 SMART GARDEN PRO

Smart Garden merupakan proyek Internet of Things (IoT) yang dirancang untuk membantu proses pemantauan kondisi tanah dan penyiraman tanaman secara otomatis.

Arsitektur Sistem

Sensor → ESP32 → WiFi → Firebase → Website Dashboard

Teknologi

Hardware: ESP32, Soil Moisture, DS18B20, Relay, Pompa.


Database: Firebase Realtime Database.


Frontend: HTML, CSS, JavaScript.


Visualisasi: Chart.js.
